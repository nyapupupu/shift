# シフト給料

バイト・インターンのシフトを入れると給料を計算する、スマホ向け Web アプリ（PWA）です。
シフトボードをもとに、**交通費を後からまとめて確認できる**ようにしています。

## できること

- **カレンダー**：シフトはバイト先ごとの色の点で表示されます。日付をタップすると、その日のシフト一覧と追加ボタンが出ます。
- **バイト先の登録**：契約の種類（アルバイト・パート／業務委託）、時給・日給、1回あたりの交通費、締め日・給料日、深夜手当の有無を設定できます。
  - **時給の改定**：「いつから・いくら」を追加すると、その日より前のシフトは前の時給のままで計算されます。
  - 日付を指定して**日給制に切り替える**こともできます。
  - **曜日・祝日の上乗せ**：「土日祝は時給＋100円」のように設定できます。祝日は振替休日・国民の休日も含めて自動で判定します。
- **シフト入力**：開始・終了・休憩・交通費を入れます。日付をまたぐ勤務にも対応しています。
  - 「この日だけ時給を変える」「この日だけ日給にする」で、年末年始などその日だけの給与にできます。
  - **単発（日給）**：登録していない仕事を、名前・日給・支払日だけで入力できます。
  - 「この内容で別の日にもコピー」で同じシフトを複製できます。
- **月収**：見込み（給与＋交通費）と、実際に振り込まれた金額（振込額・うち交通費・控除額）を分けて表示します。
- **年収**：見込みと実績の年間合計、月別・バイト先別の表を表示します。**交通費の年間合計**や**総支給額から交通費を除いた額**もここで確認できます。
- **税金用のまとめ**（年収画面）：アルバイト（給与）と業務委託（報酬）を分けて表示します。
  - アルバイト：給料日ベース。交通費（通勤手当）は非課税として給与から分けて表示。
  - 業務委託：仕事をした日ベース。支払われた交通費は収入に含め、実際にかかった交通費（自己負担分も含む）を経費として表示。
- 集計は「給料日ベース（支払われた月）」と「勤務日ベース（働いた月）」を切り替えられます。
- **Apple カレンダーへの追加**：シフトを .ics ファイルに書き出してカレンダーに読み込ませます（月ごと／まだ追加していない分／すべて）。自動では同期しないので、iPhone に「バイト」専用カレンダーを作り、変更時はそれを消して「すべてのシフトを入れ直す」で入れ直す使い方を想定しています。
- バックアップ：共有メニューから iCloud Drive に保存し、そこから復元できます。データが空のときは、カレンダー画面にも復元ボタンが出ます。

データは使っている端末のブラウザ（localStorage）の中だけに保存され、外部には送信されません。

## 使い方

ビルドは不要です。静的ファイルをそのまま配信して開きます。

```sh
npm start        # http://localhost:8080
npm test         # 給料計算ロジックのテスト
```

GitHub Pages などで公開し、スマホで「ホーム画面に追加」すれば、アプリと同じように使えます。

## ファイル構成

- `calc.js` … 給料計算ロジック（時給の履歴、深夜割増、締め日・給料日、集計）
- `holidays.js` … 日本の祝日判定（振替休日・国民の休日を含む）
- `ics.js` … シフトを .ics（iCalendar）形式に変換
- `app.js` … 画面
- `style.css`, `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`
- `test/calc.test.js` … `node:test` によるテスト

## 修正・更新とデータの引き継ぎ

データは端末の localStorage（キー `shiftpay.v1`）に保存されていて、プログラムを更新しても残ります。

- **公開先の URL と保存キー `shiftpay.v1` は変えないこと。** どちらかが変わると、別の保存場所として扱われ、データが見えなくなります。
- **データの形を変える修正をするとき**は、`migrate.js` の `CURRENT_VERSION` を1つ上げ、`MIGRATIONS` に古い形式から新しい形式への変換を追加します。起動時に自動で変換され、変換前のデータは `shiftpay.before-v<新バージョン>` に控えとして残ります。
- 保存データが読めない場合は、上書きせずに `shiftpay.unreadable` へ退避し、画面から書き出せるようにしています。
- 古いプログラムが新しい形式のデータを開いた場合は、保存を止めて再読み込みを促します。
- サービスワーカーはネットワーク優先なので、オンラインで開けば修正後のプログラムが読み込まれます。
